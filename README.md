# Dough & Dip (Pancharas Momos)

Premium Jaipur-themed restaurant website and admin dashboard for Dough & Dip / Pancharas Momos.

## Tech Stack
- HTML5 / CSS3 / JavaScript
- Vite
- Firebase Realtime Database / Authentication

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
